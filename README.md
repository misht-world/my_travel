# 🧭 Планировщик поездок

Одностраничное приложение: откройте `index.html` двойным кликом (Edge/Chrome). Установка не нужна, работает офлайн.

## Что умеет
- **Несколько поездок** с цветами, обратным отсчётом («до поездки 30 дней», «в пути — день 3 из 8»).
- **📅 По дням** — каждый день: город, переезды, заселение/выезд, места по времени, где ночуем.
  Подсвечивает **ночи без жилья**, **разрывы** и **пересечения броней**. Кнопка «🗺 Маршрут дня» строит маршрут в Google Maps: жильё → места → жильё.
  **Редактор дней:** места перетаскиваются мышью (⠿) между днями; «☑ Выбрать места» — перенос нескольких сразу; меню «⋯» у дня — вставить пустой день, удалить день (следующие подтянутся), поменять дни местами, сдвинуть всю поездку.
- **🛏 Жильё** — карточки: заезд/выезд со временем, ночи, номер брони (кнопка «скопировать»), адрес, контакт (телефон и почта кликабельны), срок бесплатной отмены (предупреждение за 3 дня), примечания, мини-карта, кнопки Google Maps / бронь / проложить маршрут.
- **📍 Места** — карточки по дням: фото или мини-карта, категория, приоритет, часы работы, описание, примечания, ссылки (карта, сайт, телефон, Википедия), отметка «посещено»; «хотелки» без даты, фильтры и поиск.
- **🚆 Транспорт** — карточки: маршрут с промежуточными точками, отправление/прибытие, время в пути, км, рейс (скопировать), мини-карта с дорогой, ссылки на билет и маршрут; кнопка ⧉ создаёт обратный переезд.
- **🗓 Календарь** — жильё полосами через ночи (цвет = город), переезды с временем в пути, ночи без жилья заштрихованы красным, дни без планов. Клик по дню открывает его в «По дням».
- **🗺 Карта маршрута** — основные точки поездки по порядку (номера), места ночёвок — красные 🏠, соединены линиями (цвет/пунктир по виду транспорта). Подложка Esri: улицы / светлая / тёмная / рельеф / спутник.
- **🌦 Погода**: у каждого дня — температура, дождь, восход/закат и «что надеть» (в заголовке дня и в календаре). На ближайшие 16 дней — прогноз, дальше — климатическая норма (среднее за 5 лет), источник Open-Meteo. Отмечается переход на зимнее/летнее время.
- **✅ Чек-лист** со стандартным шаблоном сборов и списком «Что взять» по погоде (одной кнопкой в чек-лист). **📝 Заметки**.
- **📍 Место на карте** у жилья и мест — только точные варианты: ссылка Google Maps («Поделиться» → «Копировать ссылку», короткая или полная) или координаты `45.4558, 15.5735` (правая кнопка мыши по месту в Google Maps → первая строка). Название подставляется из ссылки, его можно менять — точка не сдвинется. Предупреждение, если точка далеко от города или сдвинулась. «🗺 На карте» показывает точку, её можно поправить кликом. Короткие ссылки раскрываются, когда приложение открыто через `start.bat`.
- **🗺 Выбор на карте** (в карточке места/жилья): поиск по названию, клик или перетаскивание метки — название, город и адрес подставятся сами. В поле ссылки можно вставить и **Plus Code** (`RX38+4P, Lozovac`) или координаты (`43.805, 15.964`).

## Экспорт
- **📕 Путеводитель PDF** — красивый документ для офлайна: обложка с картой маршрута (🏠 ночёвки), сводка по дням на альбомном листе (маршрут, страна с отметкой Шенгена, время в пути и км, ночёвка, что посмотреть, примечания), календарь, каждый день с картой и местами (фото, описание, часы работы, ссылки Google Maps / сайт), раздел «Полезное» (погода и что взять, страны: деньги, дороги, роуминг), жильё с адресами и бронями, хотелки, чек-лист и заметки. В окне печати выберите «Сохранить как PDF» и включите «Фон».
  Часы работы, описание и фото берутся из OpenStreetMap и Википедии (кнопка «🖼 Часы работы и фото» во вкладке «Места» или в карточке места); можно вписать вручную.
- **📊 Excel** (.xlsx) с листами: *По дням*, *Жильё*, *Места*, *Транспорт*, *Чек-лист*. Ссылки в нём кликабельные.
- **📤 В Google Календарь** (.ics) — импорт в Google Calendar / Outlook.
- **💾 Файл / Бэкап** (.json) — сохранение и перенос на другой компьютер. Загрузка через «📂 Открыть» или перетаскиванием файла в окно.
- **🖨 Печать** — компактный план по дням (можно «Сохранить как PDF»).

## Общий доступ в домашней сети (Wi-Fi)
1. Запустите **`start.bat`** (нужен Python). В окне появятся адреса, например `http://192.168.1.23:8080`.
2. Откройте этот адрес на телефоне/ноутбуке в той же Wi-Fi сети. Все видят и редактируют одни и те же поездки; изменения синхронизируются за несколько секунд (статус внизу слева).
3. При первом запуске Windows спросит про брандмауэр — разрешите доступ для **частных сетей**.
- Пароль: впишите в `server_config.json` → `"password": "..."` и перезапустите сервер. Устройства спросят его один раз.
- Запросы не из локальной сети отклоняются. Для доступа вне дома — установите **Tailscale** на компьютер и телефоны (адреса 100.x.x.x тоже разрешены).
- Данные сервера: `data/trips.json` (+ ежедневная копия `data/backup-ДАТА.json`). Компьютер с сервером должен быть включён.
- Перенос старых поездок: откройте `index.html` как файл → 💾 Бэкап, затем в сетевой версии → 📂 Открыть.

## Безопасность и защита от случайностей
- Сервер отдаёт по сети только приложение (`index.html`, `lib/`); данные, настройки с паролем и прочие файлы недоступны. Запросы с чужих доменов (DNS-rebinding) отклоняются.
- Ссылки из данных открываются только как http(s)/телефон/почта.
- Удаление можно отменить (кнопка «Отменить» внизу); закрытие формы с изменениями требует подтверждения.

## Где хранятся данные
Данные хранятся в браузере (localStorage), сохраняются автоматически. Периодически делайте **💾 Бэкап**: если очистить данные браузера, поездки пропадут.
`lib/` — библиотеки ExcelJS (Excel) и Leaflet (карта). Если их нет, они загрузятся из интернета; без сети Excel сохранится как CSV.
